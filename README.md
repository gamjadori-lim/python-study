# 파이썬 코딩테스트 공부

코딩테스트 풀이를 문제별로 모아 두는 저장소입니다. 지금은 GitHub 연결 전에 환경이 준비됐는지 확인하는 파일만 있습니다.

## 실행

```bash
python3 test.py
```

`Hello Cursor`가 출력되면 실행 환경이 준비된 것입니다.

## GitHub에 올리기

GitHub에서 만든 퍼블릭 저장소 주소가 준비되면, 이 폴더에서 아래 순서로 연결합니다.

```bash
git remote add origin <GitHub 저장소 주소>
git push -u origin main
```

주소 예시는 `https://github.com/사용자이름/저장소이름.git` 입니다.
